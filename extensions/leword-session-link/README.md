# LEWORD 세션 연결 (크롬 확장)

크롬의 네이버·토스 로그인 세션을 이 PC 의 LEWORD 앱(127.0.0.1)으로만 보내, 제휴 수집이 로그인 풀림 없이 이어지게 합니다.

1. 크롬 주소창에 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. 이 폴더(`extensions/leword-session-link`)를 선택합니다. 크롬에서 네이버·토스에 로그인해 두고 LEWORD 앱을 켜 두면 끝입니다.

- 쿠키는 인터넷으로 나가지 않고 같은 PC 의 LEWORD 앱에만 전달됩니다.
- 확장 아이콘을 누르면 마지막 전송 시각과 결과(네이버·토스 로그인 쿠키 있음/없음)를 볼 수 있습니다.
