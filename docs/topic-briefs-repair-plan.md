# 오늘의 글감 개선 · v2.49.140

사용자 승인 범위: 확인된 비평 항목 수정, 앱·사이트 검증, 정식 릴리즈와 운영 배포.

## 구현

- 추천은 실제 목표 검색어의 측정값과 독립 검토를 통과한 작성안을 함께 요구한다. 넓어진 대안과 빈자리만으로 높은 경쟁을 추천하지 않는다.
- 경험을 확인하지 않은 사용·방문·수령 제목을 제거한다. 검색/AI 인용 성과처럼 읽히는 제목 배지를 설명/질문/수치 형태로 바꾼다.
- 기사 요약과 제한적으로 읽은 본문을 이용해 질문별 답, 정확한 근거 발췌, 부족한 자료, 목차, 독자와 접근법을 만든다. 본문 전체는 공개하지 않는다.
- 결정적인 수치·날짜·사실 오류를 자동 검사하고, 별도 AI 검토가 실패하거나 답을 뒷받침할 자료가 없으면 추가 확인으로 남긴다.
- 앱과 사이트에서 같은 작성안을 보여주고, 추천 5개 이내와 전체 탐색을 구분하며 제목 선택·작성안 복사를 제공한다.
- 기존 자료도 읽을 때 보수적으로 정리한다. 개편 화면에서 구형 별표나 경험형 제목을 그대로 노출하지 않는다.

## 검증과 배포

- 실제 비평 사례와 가상의 근거 없는 지급액으로 회귀 검증한다.
- 앱 DOM·사이트 모델/브라우저 확인 및 필요한 빌드·릴리즈 필수 검사를 통과한다.
- 실기사로 새 작성안 생성과 독립 검토를 실행하고, 운영 데이터와 표시 결과를 확인한다.
- 개인 설정을 보존한 격리 빌드로 Windows/Mac 설치판을 만든다. GitHub 공개 후 사이트 다운로드 설정을 새 버전으로 갱신한다.

구현과 관련 회귀 검증을 마쳤다. 릴리즈 필수 검사와 격리 패키징 후 배포한다. 기사 근거와 독립 검토가 충분하지 않은 글감을 추천 수를 채우기 위해 승인하지 않는다.
