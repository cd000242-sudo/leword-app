# LEWORD v2.49.139

홈판 신호에서 소재를 실제 글로 연결하는 작성안을 제공합니다.

- 사건 요약, 지금 다룰 이유, 예상 독자, 추천 관점과 질문별 근거를 함께 확인할 수 있습니다.
- 기사 요약·본문의 출처를 연결하고, 근거가 부족하거나 검토를 통과하지 못한 소재는 추가 확인이 필요한 상태로 표시합니다.
- 선택한 관점·제목·첫 카드·이미지를 저장하고 같은 선택으로 원고를 만듭니다. 근거나 선택이 바뀌면 이전 결과임을 알려줍니다.
- 사이트에서 앱 연결 없이 공개된 소재 상세와 기사 출처를 읽을 수 있습니다.
- 작성안 공개 여부를 직접 선택합니다. 개인 선택과 원고, 기사 본문 전체는 공개 파일에 포함되지 않습니다.

작성안과 원고의 AI 생성은 해당 버튼을 눌렀을 때 실행합니다. 근거가 충분하지 않은 소재의 원고 생성은 제한됩니다.
