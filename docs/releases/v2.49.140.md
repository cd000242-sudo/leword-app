# LEWORD v2.49.140

오늘의 글감에서 독자가 원하는 질문, 확인한 답, 기사 근거와 추가 조사 항목을 함께 볼 수 있습니다.

- 추천할 검색어의 의미를 유지하며, 경쟁 글이 많은 검색어를 빈자리 하나만으로 높은 적합성으로 표시하지 않습니다.
- 직접 사용·방문·수령한 적이 없는 경험을 제목으로 제안하지 않도록 검사합니다.
- 질문별 답과 정확한 발췌를 대조하고 별도 근거 검토를 거칩니다. 확인하지 못한 내용은 추가 확인으로 남깁니다.
- 앱과 사이트에 예상 독자·접근법·목차·근거를 표시하며, 제목을 선택해 작성안 전체를 복사할 수 있습니다.
- 우선 확인 후보와 전체 글감을 나누고, 구형 글감의 과한 추천 표시와 경험형 제목도 정리합니다.
- 제목 배지는 설명·질문·수치 형태로 구분하며 검색 노출이나 AI 인용 성과를 보장하지 않습니다.
- 날짜 범위를 잘못 해석하는 문제와 생성 취소 시 부분 결과가 기존 저장본을 덮어쓰는 문제를 수정했습니다.
- 앞서 반영한 황금·추천 키워드의 네이버 광고 입찰가 표시 개선도 포함합니다.
