# LEWORD 2.49.168

내 블로그 화면에서 블로그의 분야와 데이터 기준일을 쉽게 구분하고, 선택한 블로그의 글만 확인하도록 개선했습니다.

- 블로그 선택 목록에 `스타·연예 · 블로그 ID`, `자동차 · 블로그 ID`처럼 분야를 표시합니다.
- 선택 목록 오른쪽의 **블로그 바로 열기** 버튼으로 기본 브라우저를 엽니다. 최근 글 제목을 눌러 해당 원문도 열 수 있습니다.
- 블로그를 선택하면 순위 재분석 없이 최근 공개 글 목록을 새로 확인합니다. 응답의 블로그 소유 정보를 검사하며, 소유를 확인하지 못한 과거 목록은 표시하지 않습니다.
- `17시간 전` 같은 상대 날짜를 한국 시간 기준 날짜로 표시합니다. 글 목록 확인 시각과 홈판 통계 기준일을 구분합니다.
- 오래된 홈판 통계를 초록색 완료 상태로 표시하지 않습니다. 갱신이 필요하면 기준일, 선택 계정의 로그인·수집 상태, 수집 버튼을 표시합니다.
- 과거 날짜의 조회·홈판 수치를 최근 글에 붙이지 않고, 같은 블로그의 동일 글 주소로 확인된 통계만 연결합니다.
- 개인 실적 화면에 전체 블로그 홈판 순위 목록이 섞이지 않도록 정리했습니다. 분야 참고 검색어도 선택한 블로그의 분야로 제한합니다.
- 블로그를 바꿀 때 이전 블로그의 갱신 안내와 로그인 상태가 남는 문제를 수정했습니다.

홈판 통계는 전날 기준입니다. 예를 들어 10월 15일의 최신 수집 대상은 10월 14일이며, 다른 블로그의 최신 통계를 가져와 대체하지 않습니다. 해당 블로그 계정의 유효한 네이버 로그인이 필요합니다.
