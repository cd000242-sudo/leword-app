# LEWORD 2.49.175

AI 에이전트(Codex)를 쓸 때마다 터미널(cmd) 창이 뜨던 문제를 고쳤습니다.

- Codex 로 글 · 분석 · 이미지를 만들 때 매번 Windows 터미널 창이 새로 열리던 문제를 고쳤습니다. 이제 Codex 는 창 없이 뒤에서 실행됩니다.
- 원인: npm 으로 설치한 Codex 실행기가 실제 Codex 프로그램을 창 숨김 설정 없이 띄워, 콘솔이 없는 LEWORD 에서는 호출마다 새 터미널 창이 생겼습니다. 이제 LEWORD 가 실제 Codex 프로그램(codex.exe)을 직접 숨김으로 실행합니다. 찾지 못하면 이전 방식을 그대로 씁니다.
- Codex 가 쓰는 모델과 구독 한도 사용량은 바뀌지 않습니다.

검증: 새 테스트 4건(연결을 끊으면 실패하는지 확인), Codex 관련 테스트 4개 파일 19건 통과, 2.49.174 병합 뒤 sanity 전체 통과, TypeScript 검사 에러 0. 콘솔 없는 Electron 에서 이전 방식은 터미널 창 생성, 새 방식은 창 0 을 실측했습니다(Better Life Naver 같은 수정).
