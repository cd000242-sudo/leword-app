# LEWORD 2.49.170

홈판 추천판이 쓰는 "블로그 홈판 상위 이력"을 앱이 매일 자동으로 갱신합니다.

- 어드바이저 하루 수집(05:00 뒤)이 끝나면, 홈판 상위에 잡힌 글을 블로그별로 모아 추천판 수집이 읽는 이력 파일을 새로 올립니다.
- 이 이력은 홈판 추천 규칙(출처 블로그 상위 이력 1회 이상 또는 공감 10 이상)의 근거입니다. 지금까지는 손으로 한 번 뽑은 값이라 날이 갈수록 낡았습니다.
- 레포 주인 계정으로 gh 가 로그인된 PC 에서만 올립니다. 다른 PC 는 건너뜁니다.
- 원격 파일이 더 최근 날짜까지 담고 있으면 덮지 않고, 내용이 같으면 커밋하지 않습니다. 상위 기록이 없는 날은 빈 파일로 덮지 않습니다.
- 같은 글이 대소문자·모바일 주소로 따로 세지지 않게 주소를 정규화했습니다.

검증: TypeScript 빌드, 이력 추출·발행 테스트 8건(주인 PC 판정·빈 기록·원격 최신·동일 내용·새 파일·GitHub 실패·CLI 와 같은 꼴).
