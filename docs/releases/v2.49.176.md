# LEWORD 2.49.176

네이버 API HUB 키를 여러 개 넣을 수 있고, 한 키의 하루 한도가 차면 다음 키로 넘어갑니다.

- 키워드 설정의 NAVER API HUB 칸 아래에 `+ 다른 계정 키 추가`가 생겼습니다. 줄마다 Key ID · Key 를 넣고 [연결 확인]을 누르면 저장됩니다. 줄 옆에 "사용 가능 / 오늘 한도 끝 / 확인 필요"가 보입니다.
- 한 키가 "일별 사용량 한도가 초과하였습니다"로 막히면 그 키는 한국 자정까지 쉬고, 다음 키로 같은 요청을 이어서 보냅니다. 기록에는 "1번 키 오늘 한도 끝 → 2번 키로 전환"처럼 번호만 남습니다(키 값은 남지 않습니다).
- 모든 키가 끝나면 다른 길로 조용히 넘어가지 않고 "허브 키 N개 모두 오늘 한도가 끝났습니다"라고 알립니다.
- 허브 키의 한도 초과를 예전 네이버 키의 한도 초과로 잘못 적어 자정까지 전부 건너뛰던 문제를 고쳤습니다.
- 잠깐 걸리는 속도 제한에는 키를 바꾸지 않고, 무효인 키(401/403)는 그 키만 건너뜁니다.

검증: 새 테스트 4개 파일 포함 허브 관련 8개 파일 62건 통과(가짜 응답), TypeScript 검사 에러 0, 커밋 훅 sanity 통과. 진짜 한도 초과 상황과 앱 화면은 실제로 확인하지 못했습니다. 일부 호출 경로(axios)는 도중에 키를 바꾸지 못하고, 이미 한도가 끝난 키를 건너뛰는 것까지만 합니다.
