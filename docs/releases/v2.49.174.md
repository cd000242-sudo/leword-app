# LEWORD 2.49.174

홈판 추천소재 — 뉴스 기사 수 막대와 "뉴스보다 먼저였나" 실측을 붙입니다.

- 소재마다 최근 12시간 뉴스 기사 수를 30분 단위 막대로 보여 줍니다. 기사가 몰리는 시각이 한눈에 보입니다.
- 소재가 처음 잡힌 시각과 뉴스 첫 기사 시각을 견줘 "첫 기사보다 N분 먼저 / 늦게 / 미측정"으로 적습니다. 표본이 100건 상한에 닿았거나 첫 기사 시각을 알 수 없으면 미측정으로 두고 이유를 남깁니다.
- 7일 속도 성적표: 측정된 날이 7일 쌓이기 전에는 "기록 쌓는 중"만 표시합니다. 그 전에는 "빠르다"는 말을 어디에도 쓰지 않습니다.
- 네이버 뉴스 검색 요청을 10건에서 100건으로 늘렸습니다. 호출 횟수는 그대로이고 응답만 커집니다. 화면에 쓰는 기사는 이전처럼 앞 10건입니다.
- 장부 형식은 선택 항목만 더했습니다(버전 문자열 그대로). 옛 장부도 그대로 읽습니다.
- 사이트 화면(막대·배지·성적표)은 사이트 배포 뒤에 보입니다. 이번 릴리즈는 앱의 수집·장부·공개 파일 쪽입니다.

검증: 새 테스트 48건(속도 계산 33 · 배선 15) 통과, 홈판 관련 8개 파일 123건 통과, TypeScript 검사(앱·일렉트론) 에러 0. 실제 네이버 응답으로 100건 요청을 돌려 본 것은 릴리즈 뒤 첫 수집에서 확인합니다.
