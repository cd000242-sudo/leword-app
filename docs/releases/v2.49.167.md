# LEWORD 2.49.167

여러 블로그를 운영할 때 선택한 블로그의 분석·추천·유입 기록이 함께 표시되도록 개선했습니다.

- **블로그 선택:** 저장한 블로그를 드롭다운에서 고르면 해당 블로그 결과를 바로 표시합니다. 다른 계정의 통계와 추천이 섞이지 않도록 저장과 조회를 분리했습니다.
- **내 분야 추천:** 스타·연예인 블로그에 자동차나 일반 공연 예매 주제가 섞이는 문제를 수정했습니다. 후보 확장 단계에도 같은 분야 검사를 적용합니다.
- **자동 갱신:** 앱이 실행 중이면 선택한 블로그의 추천 자료를 5분마다 확인합니다. 자료가 바뀌면 추천을 갱신하고, 동일한 자료도 30분마다 다시 분석합니다.
- **매일 실적 수집:** 로그인과 블로그 소유 관계를 확인한 연결 계정별로 일일 통계를 수집합니다. 로그인 만료나 수집 실패를 완료로 처리하지 않습니다.
- **개인 성과 반영:** 해당 블로그의 최근 14일 관측 기록에서 관련 글의 홈판 유입을 확인해 추천 근거에 표시합니다. 관측 실적은 노출 확률이나 성과 보장이 아닙니다.
- **애드센스 벤치마킹:** 최근에 측정한 검색 수요·문서 경쟁·입찰가를 기준으로 후보를 정렬하고, 측정이 부족한 후보를 구분합니다. 키워드를 검토할 이유와 작성 방향을 출처와 함께 제공합니다.

자동 수집과 추천 갱신은 앱이 실행 중이고 필요한 네이버 로그인이 유효할 때 작동합니다. 변경된 자료가 없으면 같은 결과를 유지할 수 있습니다.
