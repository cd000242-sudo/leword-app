# LEWORD v2.49.141

사이트에서 생성이 실패해도 같은 PC의 LEWORD 앱에 저장된 정상 결과를 확인할 수 있도록 연결했습니다.

- 오늘의 글감과 실시간 이슈 보드는 공개 결과와 앱 저장본을 비교해 유효한 최신 결과를 표시합니다. 저장본 조회에는 AI 할당량을 사용하지 않습니다.
- 실시간 이슈의 생성 성공 시 기사 제목·이슈 설명·연관 글감도 함께 저장합니다. 실패·취소·빈 결과는 기존 정상 결과를 덮어쓰지 않습니다.
- 기사 브리프의 저장된 제목을 앱에서도 가져오며, 필요한 경우 버튼으로 앱에서 제목을 생성할 수 있습니다. 기사 근거가 있는 검색어만 생성합니다.
- 오늘의 글감 사이트 화면에 회차·분야 탐색, 근거 검토 상태, 질문별 답변과 작성 순서를 강조했습니다.
- 오늘의 네이버 추천 키워드는 한국 시간 오전 06:30, 오후 13:30, 저녁 19:30에 갱신합니다. 신규·변경·유지 항목과 실제 측정 시각을 구분합니다.
- 같은 회차의 재시도와 최근 측정값 재사용으로 중복 조회를 줄이고, 불완전한 수집 결과는 공개하지 않습니다.

앱 저장본을 보려면 이 버전의 앱을 같은 PC에서 실행하고 유효한 라이선스로 이용해야 합니다. 앱에서 한 번 이상 정상 생성한 결과가 필요합니다.

## Mac 설치 안내

Mac 설치판은 서명 인증서가 설정되지 않은 빌드입니다. macOS 보안 확인이 필요할 수 있으며, 자동 업데이트가 원활하지 않으면 해당 기종의 DMG를 내려받아 설치해 주세요.
