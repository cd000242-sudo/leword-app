# LEWORD 2.49.169

내 블로그 화면에서 선택한 계정의 네이버 로그인이 필요하면 안내 창을 먼저 표시합니다.

- 안내 창에 블로그 분야와 아이디를 표시하고, **네이버 로그인** 버튼으로 해당 블로그의 로그인 창을 엽니다.
- 로그인한 계정에 선택한 블로그가 연결되어 있는지 확인한 뒤 홈판 통계를 자동으로 수집합니다. 다른 계정의 로그인만으로 수집을 시작하지 않습니다.
- **나중에**를 누르면 같은 앱 실행 중 해당 블로그의 안내를 반복해서 띄우지 않습니다. **지금 통계 수집**을 누르면 로그인 필요 여부를 다시 확인합니다.
- 로그인 창을 닫거나 블로그를 바꾸면 이전 로그인 대기 작업을 중단합니다. 네이버 연결 오류는 로그아웃과 구분합니다.
- 로그인 전 화면 조회가 실패한 통계 수집 기록을 남기지 않도록 개선했습니다.

홈판 통계의 최신 수집 대상은 전날입니다. 로그인은 사용자가 네이버 창에서 직접 완료해야 하며, 이 업데이트가 과거 자료를 오늘 자료로 바꾸지는 않습니다.

검증: TypeScript 빌드, 계정 소유 확인·로그인 만료·연결 장애 테스트, 실제 Chrome에서 로그인 안내·취소·자동 수집 연결·블로그 전환 회귀 테스트.
