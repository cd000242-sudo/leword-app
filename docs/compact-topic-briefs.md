# 오늘의 글감 — 집필용 카드

2026-09-28 사용자 요구에 맞춰 대형 소개·체험 편집기를 카드 중심 목록으로 교체한다. 시기/분야, 핵심 검색어, 월 검색량, 블로그 문서량, 상위 10개 경쟁, 대안, 사건 요약, 검색/홈판 제목, 작성 방향, 필수/제외 내용, 관련 표현, 출처 페이지의 이미지·캡처 안내를 순서대로 제공한다.

지원금·사업·경제·이슈 분야를 우선 발굴한다. 첫 발굴 후 중복을 제거한 글감이 50개 미만이면 최대 2회 보충한다. 수량 완료와 근거 검토 완료는 별개로 기록하며, 미확인 글감을 추천으로 승격하지 않는다. 50개 미만인 회차는 예약 재시도 대상이다. 같은 날짜·회차의 더 풍부한 기존 결과를 적은 결과로 덮지 않는다.

완성 원고 생성은 기본 발굴 과정에서 제외한다. 분야별 자료 읽기는 최대 12건, 기사별 기존 시간/용량/호스트 제한을 유지한다. 생성 호출 전체 상한과 발굴 전체 시간 상한을 두고 취소는 즉시 전파한다.

문서량은 Blog OpenAPI의 동일 검색어 측정값과 원래 측정 시각이 있을 때만 표시한다. 상위 10개 정면 글 수를 전체 문서량으로 사용하지 않는다. 홈판 제목의 따옴표 문구는 편집용 후킹이며 인물 발언을 꾸미지 않는다. 이미지 안내는 인용된 출처 페이지와 실제 자료 내용만 연결하며 이미지 파일 주소나 이용 권한을 추정하지 않는다.

검증은 발굴 보충/중복/기존 회차 보존/취소/시간 한도, 출처 기반 가이드/따옴표 제목, 날짜 공백, 문서량 측정 출처, 공개 캐시 보존, 카드 내용·복사·접근 제한을 포함한다. 실제 게시 건수와 배포 결과는 작업 보고에서 확인한다.

2026-09-28 확장: 기본 목표 50개(설정 1~100). 지원금·복지 15, 비즈니스·소상공인 15, 경제·금융 10, 생활경제·부동산 5, 주요 이슈 5를 배정한다. `--goal`, `--mainCategories` 또는 로컬 실행 옵션으로 목표와 메인 분야를 바꿀 수 있다. 기본 메인 비중은 80%이며 실제 확보가 부족하면 부족 수량을 그대로 남긴다. 사이트의 “먼저 볼 분야”는 개인 표시 순서 설정이며 공동 생성 배분은 변경하지 않는다.

검색량은 정확한 동일 검색어의 네이버 검색광고 PC·모바일 응답, 공개 제한 플래그와 원 조회 시각을 함께 저장한다. 매 회차 fresh 조회를 기본으로 한다. 두 기기가 모두 숫자일 때만 합계 숫자를 표시하고, 한 기기 100 / 다른 기기 <10이면 100~109, 두 기기 <10이면 0~18로 표시한다. API 실패·누락과 <10을 혼동하지 않는다. 월간 조회값은 오늘 또는 미래의 실시간 검색 수요를 뜻하지 않는다.
