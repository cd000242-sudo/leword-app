## 카드 샘플 1 — ★ 우선 검토: 장기전세 20년 만기

**카테고리:** 생활경제·주거 / **작성 시점:** 9월 28일 밤~29일 오전 재확인 후 / **형태:** 다시 관심받는 정책 해설

**추천 근거:** [hitthemoney의 9월 27일 글](https://blog.naver.com/hitthemoney/224423677591)과 [이슈링크에 잡힌 당일 커뮤니티 글](https://www.issuelink.co.kr/community/go/fmkorea/10384797333)에서 같은 주제가 포착됐다. 23시 무렵 집계 목록에는 해당 글이 6위, 댓글 885개로 표시됐다. 단일 시점의 집계값이며 댓글 증가나 네이버 홈판 노출을 확인한 것은 아니다.

**무슨 일이 있었나:** 20년 만기를 앞둔 장기전세주택의 처리 방식이 다시 논의되고 있다. 새로운 정책 발표라고 쓰지 않는다. 서울시의 기존 설명과 현재 입주자가 확인할 항목을 구분하는 글이 적합하다.

**키워드:** 장기전세 20년 만기

**검색량 / 문서량 / 상위노출 가능성:** 이번 조사에서 실측하지 않음 / 미측정 / 판정 보류. 885개 댓글을 검색량으로 표시하지 않는다.

**대안 키워드:** 장기전세 만기 이후, 장기전세 분양전환, 장기전세 미리내집 차이. 검색량과 경쟁도를 측정하기 전에는 ‘황금키워드’라고 부르지 않는다.

**검색형 제목:** 서울 장기전세 20년 만기, 계약 연장·분양전환·이주 지원 확인할 점

**홈판형 제목:** “20년 살면 내 집이 될까?” 장기전세 만기 전에 확인할 세 가지

따옴표 부분은 독자의 질문을 표현한 제목 초안이며 실제 입주자 발언을 인용한 것이 아니다.

**작성 방향:** 입주자를 비난하거나 갈등만 재생산하지 않는다. ‘만기 원칙 → 이주 지원 확인 → 다른 주택 유형과의 차이’ 순서로 독자의 질문에 답한다.

**반드시 포함:** 적용되는 주택 유형, 개별 계약 확인, 서울시 설명의 날짜, 공식 상담 안내, 조건부 지원과 자동 보장의 차이.

**넣지 않을 내용:** 전 가구가 같은 금액을 받는다는 단정, 새로운 일괄 보상금이 생겼다는 주장, 장기전세Ⅰ과 미리내집 혜택 혼용, 오늘 처음 발표됐다는 표현.

**함께 넣을 말:** 임대차계약, 최장 거주기간, 재공급, 입주요건, 이주 상담, 장기전세Ⅰ, 장기전세Ⅱ.

**이미지·캡처 지점:** [서울시 설명](https://mayor.seoul.go.kr/oh/seoul/newsView.do?curPage=1&photoGallerySn=4651)에서 ‘20년간 주거안정’ 소제목 아래 만기·이주 안내 부분을 확인한다. 페이지 제목·확인 날짜·출처를 함께 남긴다. 이미지 재사용 조건은 별도로 확인하고, 설명용 비교표는 직접 만든다. 벤치마크 블로그의 사진을 그대로 옮기지 않는다.

## 카드 샘플 3 — 시점 재검토: 뿌요뿌요 아시안게임

**카테고리:** 게임·스포츠 / **발견:** [honestpsc17, 9월 26일 글](https://blog.naver.com/honestpsc17/224423449872)

**확인:** 원문에서 공감 10개를 관찰했다. 조회수·증가 추세는 미확인이다. [일본 올림픽위원회](https://www.joc.or.jp/aichi_nagoya2026/esports.html)와 대회 종목 자료에 게임이 포함돼 있다.

**판단:** ‘추억의 게임이 정식 종목’이라는 놀라움은 있으나 채택 자체는 새 발표가 아니다. 최신 공식 결과·선수의 새로운 이야기를 확보하면 새 카드로 재평가한다. 이미 종료된 경기를 앞으로 열릴 경기처럼 추천하지 않는다.

## 구현안

1. **수집:** 출처별 RSS·공개 페이지 어댑터를 둔다. `publishedAt`, `eventAt`, `capturedAt`을 분리하고 플랫폼별 수집 상태를 표시한다. 로그인 필요·실패·오래된 캐시를 숨기지 않는다.
2. **검토:** 사건별 중복을 묶고 원출처를 추적한다. 예전 사건, 협찬, 사실 확인 부족, 이미 종료된 일정은 별도 상태로 내린다.
3. **추천:** 사건의 현재성, 공개 반응, 여러 커뮤니티로의 확산, 독자가 얻을 정보, 다른 글과 구별되는 관점, 확보 가능한 이미지로 우선순위를 결정한다. 카테고리 고정 쿼터는 없다.
4. **반응 비교:** 플랫폼별 같은 지표를 여러 시점에 저장하고 채널의 비슷한 발행 경과 시간과 비교한다. 첫 수집에는 증가율을 만들지 않는다. YouTube 조회수와 블로그 공감을 직접 같은 수치로 합산하지 않는다.
5. **화면:** ‘지금 쓸 글 / 원출처 확인 중 / 시점 지난 글’ 탭, 추천 별, 추천 이유, 실제 원문, 제목 2종, 작성 방향, 포함·제외 내용, 이미지 안내, 출처를 카드에 제공한다. 홈판 노출 여부는 별도 필드다.
6. **정확성:** 노출 관측 또는 사용자 유입 자료가 없는 상태에서는 확률을 출력하지 않는다. 검색량은 실제 조회한 값·기준 기간·조회 시각을 함께 표시하며 실패하면 미측정으로 남긴다.
7. **앱·웹 공유:** 새 벤치마크 보드를 별도 버전으로 저장하고 웹 발행 경로에 연결한다. 앱의 마지막 성공 데이터와 웹 데이터를 맞추며, 오래된 자료를 최신 성공으로 바꾸지 않는다. AI 요약 실패와 원천 수집 성공을 별개로 관리한다.

검증해야 할 핵심 사례: 옛 사진의 새 발행, 같은 기사 복제, 유효하지 않은 날짜, 첫 관측 증가율, 부분 수집 실패, Instagram 미확인, 검색량 미측정, 늦은 경기 일정, 사실 확인되지 않은 인물 주장.

현재 홈판은 이슈 키워드 중심이며 채널별 게시물 이력은 없다. 앱의 `src/main/homefeed`에 수집·저장을 확장하고, 웹의 `HomefeedTab`·`HomefeedCard`에 새 추천 화면을 연결해야 한다. 기존 `homefeed-stories.json`에는 작업 중 변경이 있어 이번 조사에서 건드리지 않았다.
