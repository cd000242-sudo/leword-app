# 오늘의 글감 작성실 베타 — 2026-09-28

이번 적용 범위는 사이트의 작성·편집 테스트 화면과 공통 생성기의 작성 패키지 계약이다. v6 설계 전체의 공식 자료 수집·분야/플랫폼 개인화·성과 추적을 구현했다는 뜻은 아니다.

- 실제 추천 판정을 통과한 모든 글감에 ★ 추천 글감 표시. 순서나 색상으로 추천을 만들지 않는다.
- 보라·시안·핑크 히어로와 골드 추천 배지, 키워드 칩, 대비를 높인 카드.
- 독립 검토를 통과한 원고의 본문·표·FAQ·출처 표시, 제목/본문 편집, 편집본 복사, 원본 복원.
- 공식 네이버 자료 기반 체험 원고는 로그인 없이 제공. 일일 추천과 분리하며 수요·경쟁 미측정 표시. 일일 보드의 계정/무료 범위는 유지.
- 수정 내용은 페이지 메모리에만 보존. 체험 패널을 접어도 보존하지만 새로고침·페이지 이동 전에는 복사가 필요하다.
- 생성과 검수는 명시적 배치 작업에서만 호출. GET은 AI를 실행하지 않음. 전체 배치의 작성 패키지 시도는 최대 3개.
- 뉴스 사실 검토와 작성 패키지 완성도는 독립 상태. 작성 패키지 완료가 SEO 추천이나 수익 검증을 뜻하지 않음.

기존 공개 글감 중 사실 검토를 통과한 4개로 실생성을 시도했으나 모두 중요한 추가 확인 사항이 남아 패키지를 게시하지 않았다. 부족한 자료를 임의로 채우는 대신 기존 보드와 공식 자료 체험 원고를 제공한다. 이는 공식 자료를 더 깊이 수집해야 한다는 v6 후속 과제의 실제 확인 결과다.

검증: 생성기·공개 캐시 테스트, 사이트 모델·편집/복사·추천 별·무료 범위 테스트, 타입 검사, 브라우저에서 편집→접기/펼치기→출처 포함 복사, 모바일/데스크톱 가로 넘침 확인. 배포 결과는 최종 작업 보고에서 확인한다.
