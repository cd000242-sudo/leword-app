# 황금키워드의 경제·지원금과 최근 추세

2026-09-28 공개 보드 감사: 145행 중 비즈니스·경제는 2행이며 두 행 모두 9월 7일 검색결과였다. 59행의 `상승세`는 월별 장기 추세여서 오늘의 경제 이슈를 의미하지 않았다. 실시간 스냅샷은 대조용으로만 쓰였고 새 후보를 공급하지 않았다.

## 발굴

- `preemption-current-sources.js`가 최근 7일 기사 출처가 있는 오늘의 글감 및 1일 이내 실시간 경제 키워드를 후보로 연결한다.
- 지원금·소상공인·경제·주거를 순환 선정하고, 기존 씨앗과 측정 표본의 정원을 대체한다. 출처 URL과 실제 기사 시각을 `currentSource`로 보존한다.
- 직접 키워드를 먼저 실측하고 검색광고 연관어·자동완성으로 확장한다. PC/모바일 검색량의 미측정 및 `<10`을 정확한 합계로 만들지 않는다.
- 월·금 회차, SearchAd/BrightData 예산, 기존 SERP 통과 기준은 유지한다.

## 최근 추세

`golden-short-trend.ts`는 데이터랩에서 집계가 끝난 연속 14일을 사용한다. 최근 7일 합계를 직전 7일 합계로 나눈 값이 1.2 이상이면 상승, 0.8 이하이면 하락이다. 기준 합계 0, 결측, 오래된 집계는 미확인이다. 집계 기준일과 조회 시각은 3일 이내여야 하며 오늘의 미완료 데이터는 제외한다.

`publish-preemption-board.js`는 최근 7일 이내 검색결과를 측정한 행을 대상으로 제한된 일별 조회를 수행한다. 기존 검색결과 확인일을 새 발행일로 바꾸지 않는다. 광고 3위 입찰가는 광고주 경쟁 지표이며 애드센스 예상 수익으로 표시하지 않는다.

## 사이트

전체 목록에서 경제·지원금을 우선 정렬하고 경제·지원금 / 최근 상승 / 고단가 상승 필터를 제공한다. 고단가 상승은 실측 입찰가 3,000원 이상과 최근 상승을 모두 충족해야 한다. 오래된 행은 재확인 필요로 표시한다.

최근 수요가 올라도 기존 황금 게이트를 통과하지 못한 경제 키워드는 `trendCandidates`에 분리한다. 실제 상위 제목 표본과 경쟁 상태가 있어야 하며 황금 배지를 붙이지 않는다. 무료 5개 고정 정책은 유지하고 트렌드 후보가 새 무료 표본을 만들지 않도록 한다.

검증은 후보 출처·분야 배분·검색량 정확성, 14일 추세와 만료 처리, 공유 조회 예산, 트렌드 전용 회차의 기존 보드 보존, 화면 필터와 고정 무료 표본을 다룬다.
